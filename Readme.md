# AI Gesture Controlled 3D Particle Morphing System

An interactive WebGL-based 3D particle system controlled using real-time hand gestures via MediaPipe Hands.

## Features
- Real-time hand tracking using MediaPipe
- 15,000 GPU-accelerated particles
- Smooth particle morphing between procedural 3D shapes
- Gesture-based shape switching
- Pinch interaction for expansion and color effects

## Gesture Controls
| Fingers | Shape |
|-------|------|
| 1 | Sphere |
| 2 | Heart |
| 3 | Flower |
| 4 | Saturn |
| 5 | Fireworks |

## Tech Stack
- Three.js
- MediaPipe Hands
- WebGL
- JavaScript
- HTML5 Canvas

## How to Run
1. Clone the repository
2. Open `index.html` in a browser
3. Allow camera access
